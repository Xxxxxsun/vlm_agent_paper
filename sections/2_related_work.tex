\label{sec:related_work}

\paragraph{Self-improving agents.}
A growing line of work lets LLM agents improve from experience without gradient updates:
Reflexion~\citep{shinn2023reflexion} keeps a verbal reflection buffer that resets between
episodes; Voyager~\citep{wang2023voyager} and ExpeL~\citep{zhao2023expel} accumulate
persistent skill libraries in game and tool-use domains;
AutoManual~\citep{chen2024automanual} and EvolveR~\citep{evolver_2025} refine instruction
manuals or reasoning strategies via self-play. All operate in text, code, or game domains,
never generating executable visual processing nor deciding whether a bottleneck is cognitive
or perceptual. \sysname{} extends the persistent-library paradigm into the visual domain
with a multimodal diagnostic that text-only frameworks cannot perform.

\paragraph{Tool creation for language models.}
A complementary line generates new tools on demand:
CREATOR~\citep{tang2023creator} prompts an LLM to write Python helpers for problems it
cannot solve directly; LATM~\citep{cai2024latm} and ToolLLM~\citep{qin2024toolllm} scale
this to large API collections. These methods generate tools in textual or mathematical
domains and do not profile when a generated tool succeeds or fails---a gap that matters for
visual tools, where the same operation can help on most images but hurt on specific patterns
(e.g.\ a sharpening filter degrading low-contrast charts). \sysname{}'s mastery phase
profiles each tool on a held-out case set to characterise its applicability before
promotion.

\paragraph{Visual reasoning with tools.}
Several recent systems equip VLMs with visual processing tools. VTool-R1~\citep{vtoolr1_2025},
DeepEyes~\citep{deepeyes_2025}, Adaptive-CoF~\citep{adaptivecof_2025},
PixelReasoner~\citep{pixelreasoner_2025}, and V-Thinker~\citep{vthinker_2025} all rely on
SFT and/or RL with curated trajectories to teach a VLM when and how to invoke a fixed tool
inventory. ZoomEye~\citep{zoomeye_2024} and ReFocus~\citep{refocus_2025} are training-free
but assume a fixed zoom/search algorithm or visual-editing interface. \sysname{} instead
generates and validates the skills and tools themselves from the agent's own behaviour on a
small training subset, with no weight updates and no predefined tool inventory.

\paragraph{Tool-augmented VLMs with predefined tool sets.}
VisProg~\citep{gupta2023visprog}, ViperGPT~\citep{suris2023vipergpt}, and
Chameleon~\citep{lu2024chameleon} compose hand-curated tool libraries (detectors, OCR,
arithmetic modules) via program synthesis. They handle broad compositional visual tasks
effectively but cannot recover when the required tool is missing from the human-designed
inventory. \sysname{} fills this gap by generating new tools when the current set is
insufficient, bridging fixed-tool composition and training-based tool learning.
